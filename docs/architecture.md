# Архитектура

educatioHarness разделён на три процесса: Tauri отвечает за окно, команды, SQLite и системное хранилище секретов; React отображает состояние; Node.js runtime выполняет запросы Codex SDK или OpenAI Responses API. Фронтенд не получает ключ API. Запрос модели передаётся дочернему процессу через stdin, прогресс и результат — ограниченными JSONL-событиями через stdout. Tauri пересылает только число полученных символов в UI: непроверенный JSON и скрытое решение задания не показываются. Нет локального HTTP-сервера для агента.

`src/features/learning/engine.ts` задаёт специализацию обучения: диагностика, оценка, план, урок, практика и извлечение графа. `agent-runtime/src/main.ts` содержит небольшой провайдерный интерфейс и схему структурированных результатов. Другой workflow сможет использовать тот же транспорт и хранилище, добавив собственные операции и навыки.

SQLite открывается только в Rust (`src-tauri/src/lib.rs`). Миграции находятся в `migrations/`, версия хранится в `PRAGMA user_version`. Транскрипты, диагностические ответы, темы, попытки, граф и состояния шагов — отдельные таблицы с внешними ключами. Команды записи ограничены перечнем таблиц и полей. Значимые переходы workflow сохраняются до и после вызова модели. После перезапуска незавершённую диагностику можно повторить явно; операции не перезапускаются автоматически. Уже записанные ответы подставляются обратно в форму, а незавершённый учебный план скрыт до успешного окончания шага и заменяется целиком при повторе.

Родной процесс Codex использует официальный вход `codex login`. SDK создаёт и возобновляет thread; его ID хранится отдельно для каждой операции и учебной сессии. Codex SDK `runStreamed` и OpenAI Responses `stream: true` дают события выполнения. OpenAI SDK вызывается только с API-ключом из системного хранилища. Ключ передаётся дочернему процессу через переменную окружения, не через renderer или SQLite. Каждый вызов имеет таймаут 180 секунд и может быть отменён. В production Node поставляется отдельным исполняемым sidecar, а runtime — собранным модулем.

Граф хранит объективные утверждения и цепочки совместных посылок. Источники фиксируются в `knowledge_provenance`. Узел не означает, что ученик усвоил утверждение. Автоматический layout React Flow строится по цепочкам, а выбор узла открывает редактирование и источники.
