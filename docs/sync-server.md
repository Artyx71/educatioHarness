# Свой сервер для защищённых архивов

Это минимальный одно-пользовательский сервер передачи `.ehb`, а не сервер учебных занятий. Он хранит зашифрованные архивы целиком и не знает пароль архива, API-ключ или сессию ChatGPT. Регистрации, профилей и автоматического слияния изменений пока нет.

Требуется Node.js 22+ и абсолютный каталог данных. Пример запуска на серверной машине:

```sh
export EDUCATIO_SYNC_DATA_DIR=/srv/educatio-sync
export EDUCATIO_SYNC_TOKEN='случайная-секретная-строка-не-короче-32-символов'
npm run sync-server:start
```

Сгенерируйте токен генератором криптографически случайных байтов, например `node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"`. Не коммитьте и не записывайте токен в `.env` внутри репозитория. При запуске сервер слушает только `127.0.0.1:8787` (порт меняется через `EDUCATIO_SYNC_PORT`). Для доступа с другого устройства нужен доверенный HTTPS reverse proxy или приватный туннель с HTTPS. Прямой HTTP в локальную сеть не открывается; приложение не принимает удалённый HTTP-адрес.

В приложении откройте «Настройки → Свой сервер», введите базовый HTTPS-адрес и токен. Проверка делает настоящий HEAD-запрос. Токен сохраняется в системном хранилище секретов на каждом устройстве отдельно, адрес — в локальных настройках. Затем:

1. Создайте защищённый `.ehb` в «Перенос данных».
2. В «Свой сервер» укажите пароль этого архива и выберите файл для отправки. Пароль проверяется локально и не отправляется серверу.
3. На другом компьютере подключите тот же сервер и скачайте архив. Импортируйте его через «Перенос данных», введя пароль.

Сервер требует токен для GET/HEAD/PUT `/v1/archive`. `GET /health` не раскрывает данные и не требует токена. Перед заменой текущего архива клиент использует ETag/If-Match; сервер отвечает `412`, если архив успел измениться. Первое размещение требует `If-None-Match: *`. Предыдущие объекты остаются на диске по SHA-256 и могут быть восстановлены вручную администратором, но пользовательского интерфейса версий пока нет. Ограничение — 100 МБ исходной базы плюс 52 байта заголовка и тега. Защита от одновременных PUT действует внутри одного процесса; запускайте только один экземпляр на каталог. Резервное копирование каталога сервера остаётся обязанностью администратора.

Отключение в настройках удаляет локальный токен и адрес, но не удаляет удалённый архив. Чтобы отозвать доступ, смените `EDUCATIO_SYNC_TOKEN` на сервере и заново подключите доверенные устройства. Для нескольких пользователей нужен отдельный серверный протокол с аккаунтами; этот MVP не выдаёт один токен нескольким людям.

Проверка сервера: `npm run sync-server:test`.
