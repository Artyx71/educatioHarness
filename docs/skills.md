# Навыки агента

Каждый навык находится в `<каталог>/<name>/SKILL.md` с метаданными `name` и `description` согласно [Agent Skills specification](https://agentskills.io/specification). Rust обнаруживает только метаданные. Runtime выбирает навык по операции и загружает его полный текст только перед соответствующим вызовом. Содержимое занятия передаётся отдельно как недоверенные данные. Навык не может расширить права Codex sandbox; `allowed-tools` из импортированного файла не даёт разрешений приложению.

Встроены `knowledge-probe`, `curriculum-planner`, `socratic-teacher`, `knowledge-extractor`, `knowledge-auditor`, `exercise-generator`, `answer-evaluator`. Их методика адаптирована из LearnHarness; сведения об источнике в [upstream-reuse.md](upstream-reuse.md).

Чтобы подключить свои навыки, откройте «Настройки → Навыки агента», укажите до пяти абсолютных путей к каталогам и сохраните. Каждый каталог содержит папки навыков. Затем выберите навык для нужного шага. Если имя совпадает со встроенным, приоритет остаётся у встроенного навыка. Файл `SKILL.md` должен быть обычным файлом, а не символьной ссылкой; модели не предоставляются инструменты выполнения скриптов из навыка. Схема результата каждого шага остаётся фиксированной и валидируется после ответа модели. Дополнительные ресурсы навыка пока не подгружаются автоматически.

Добавление нового встроенного навыка: создать каталог с `SKILL.md`, указать метаданные, добавить операцию и схему результата в `agent-runtime/src/main.ts`, связать операцию с навыком в `src/features/learning/engine.ts`.
